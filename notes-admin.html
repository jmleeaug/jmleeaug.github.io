관리자 연결

본인 GitHub 계정의 연결 키로 권한을 확인합니다. 키는 이 창을 닫으면 잊어버리며, 파일이나 브라우저 저장소에 저장하지 않습니다.

처음 연결하는 방법
  1. GitHub 연결 키 만들기를 엽니다.
  2. Resource owner는 jmleeaug, 만료일은 원하는 기간을 선택합니다.
  3. Repository access는 Only select repositories에서 jmleeaug.github.io만 선택합니다.
  4. Repository permissions의 Contents → Read and write를 선택합니다. Metadata 읽기 외에 다른 권한은 필요하지 않습니다.
  5. Generate token을 누르고 나온 키를 이 화면에 붙여넣습니다. 키를 채팅으로 보내거나 홈페이지 파일에 넣지 마세요.

연결 키는 이 저장소의 파일을 수정할 권한이 있습니다. GitHub에서 언제든 폐기할 수 있고, 만료되면 새 키로 연결하면 됩니다.
